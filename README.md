# 🛒 CodeAlpha E-commerce Website

A simple and user-friendly e-commerce web application built using Django, Python, HTML, and CSS.

## 📌 Project Overview

This project is a Django-based online shopping website where users can browse products, view product details, add products to a shopping cart, manage quantities, and place orders through a checkout page.

## ✨ Features

- 🏠 Professional home page
- 🔍 Product search
- 🖼️ Product images
- 📋 Product details page
- 🛒 Add to Cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Remove products from cart
- 💰 Automatic total price calculation
- 🛒 Checkout page
- 👤 Customer details
- 📦 Place Order
- 🎉 Order confirmation page

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git
- GitHub

## 🎯 Project Goal

The goal of this project is to develop a functional e-commerce website and gain practical experience with Django, Python, database integration, frontend development, and GitHub.
